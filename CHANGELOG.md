# Changelog

## 0.3.0 — 2026-11-18

- Added monotonic observed revisions and `expected_revision` conflict protection.
- Added 20–60 second canvas-change long polling with normal timeout results.
- Added dirty-bounds-aware region previews.
- Added explicit save, save-as, export, document listing, activation, and close tools.
- Added text-layer creation and editing.
- Added opacity, flow, spacing, smoothing, roundness, per-point pressure, and verified erase strokes.
- Added layer deletion, groups, canvas/image resize, crop, rotate, and lightweight collaboration sessions.
- Preserved the existing 29-tool surface and expanded it to 49 curated tools.
